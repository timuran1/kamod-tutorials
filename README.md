# KAMOD Tutorials

21 short video lessons for [KAMOD](https://kamod.io).
Watch, download and check yourself: https://timuran1.github.io/kamod-tutorials/

Lessons 1–16 are available in English, Russian and Uzbek. Lessons 17–21 are available in Russian and Uzbek.
Every lesson includes a 16:9 desktop edition and a 9:16 mobile edition.

New lessons cover Video Remix, Omni Edit character replacement, rain and lightning effects, Omni Flash 1.2 text/image-to-video, and AI Influencer character images.
Videos use web-optimized H.264/AAC with faststart. Original masters are retained separately.

Videos: `en/`, `ru/`, `uz/`, `new-lessons/` · lesson list: `lessons.json` · portrait builder: `build_portraits.py`.
